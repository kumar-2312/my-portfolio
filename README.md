# Kumar G — Portfolio Website

A responsive personal portfolio built with plain HTML and CSS. It uses the profile photo supplied with the project and the details from the supplied resume.

## Preview locally
1. Download and extract `kumar_portfolio.zip`.
2. Open `index.html` in your browser.

No build tools or dependencies are required. Google Fonts are loaded online; the site still works if they are unavailable.

## Publish on GitHub Pages
1. Sign in to GitHub and create a new **public repository** named `kumar-portfolio` (or another name you prefer).
2. Upload `index.html`, `style.css`, the `assets` folder, and this `README.md` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then click **Save**.
6. Wait for GitHub Pages to publish. Your website URL will appear in the Pages settings.

## Customize
- Update contact details in `index.html` if they change.
- Replace `assets/profile.jpg` to use a different profile photo.
- Edit colors and spacing in `style.css`.

## Project files
- `index.html` — portfolio content and page structure
- `style.css` — responsive styling
- `assets/profile.jpg` — profile image
